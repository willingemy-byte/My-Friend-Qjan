BAYTON / AOSP
Source: https://github.com/jasonbayton/11ty
Permission catalogue: _src/_data/android_permissions.json
Generator: scripts/gen_permissions.js
APK inspector reference: _src/_includes/_assets/js/apk-inspector.js
Attribution: Jason Bayton; Android Open Source Project contributors.
The catalogue is derived from AOSP AndroidManifest.xml and permission strings;
those upstream source links, Android release and API are preserved in bayton.json.
AOSP source is distributed under Apache License 2.0:
https://www.apache.org/licenses/LICENSE-2.0
Bayton repository licence: https://github.com/jasonbayton/11ty/blob/main/LICENSE
Its licence distinguishes MIT website code from written content/resources
(attribution terms identified upstream as "CC-BY-NA"). Upstream notice is retained
in BAYTON-LICENSE.txt. No APK-inspector implementation was copied into AIV.
The public catalogue supplies reference descriptions, not the actual permissions
granted on a user's device, Google Play disclosures, or a publisher verification.

EXODUS PRIVACY
Source: https://reports.exodus-privacy.eu.org/api/trackers
Catalogue and signatures: Exodus Privacy and contributors.
Tracker database: Open Database License (ODbL) 1.0;
individual contents: Database Contents License (DbCL) 1.0.
https://opendatacommons.org/licenses/odbl/1-0/
https://opendatacommons.org/licenses/dbcl/1-0/
The exodus.json database is an attributed extraction, distributed under those
terms. It includes IDs, names, signatures, categories and website URLs; narrative
descriptions have been omitted. It is separate from AIV code and private results.
Upstream SHA-256, source and retrieval date are preserved. No Exodus server,
Android client or exodus-core source code was copied into AIV.

SCOPE
Both databases may be incomplete or newer than the phone's Android release.
A match is a signature observation, not proof of execution, transmitted content,
malware, or server-side processing. An absent match is not a safety certificate.
